# TODO App

PHPセッションを使ったシンプルなTODO管理アプリです。

## 機能

- タスクの追加・編集・削除
- 完了トグル / 完了済み一括削除
- 優先度設定（高・中・低）— 左ボーダーの色で視覚的に区別
- 期限日設定 — 期限超過時に警告表示
- フィルター表示（全件 / 未完了 / 完了済み）
- 進捗バー・統計表示

## ファイル構成

```
todo_clodecode/
├── todo.php           # エントリーポイント
├── actions.php        # POSTアクション処理
├── style.css          # スタイルシート
└── views/
    ├── stats.php      # 統計・プログレスバー・フィルタータブ
    ├── form.php       # タスク追加フォーム
    ├── list.php       # TODOリスト
    └── edit_modal.php # 編集モーダル
```

## 動作環境

- PHP 8.0 以上
- セッション有効なWebサーバー（Apache / Nginx など）

## 使い方

1. Webサーバーのドキュメントルートにファイルを配置
2. ブラウザで `todo.php` にアクセス

```bash
# PHP組み込みサーバーで起動する場合
php -S localhost:8000
```
